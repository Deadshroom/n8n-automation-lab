# n8n N8N101 Training

This directory contains hands-on workflow implementations associated with the N8N101 training material represented in this repository.

The examples currently preserved here focus on foundational workflow construction, HTTP API interaction, data transformation, branching, aggregation, and report generation.

## Examples

### Academy Registration
A small API workflow that registers the training workflow with the n8n Academy endpoint.

`academy-registration/`

### Sales Data Pipeline
A multi-branch data-processing workflow that retrieves sales data, calculates order totals, filters delivered orders, summarizes results by region, creates a CSV report, and submits multiple outputs.

`sales-data-pipeline/`

## Public Export Note

Environment-specific identifiers and credential references are sanitized before publication. Imported workflows may require credential and placeholder reconfiguration before execution.
