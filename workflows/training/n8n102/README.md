# n8n 102 Workflows

Workflows completed as part of n8n training and hands-on experimentation.

These exercises demonstrate practical implementation of workflow orchestration,
API integrations, data processing, conditional logic, and error handling in n8n.

## Workflows

### API Integration Pipeline

**File:** `api-integration-pipeline.json`

An API-driven order processing pipeline that retrieves orders and customer
records, enriches order data, and routes records according to business rules.

Concepts demonstrated:

- REST API requests
- Header-based authentication
- API pagination
- Parallel workflow execution
- Dataset merging and enrichment
- Conditional branching
- Filtering
- Switch-based routing
- Batch processing
- POST requests
- Retry/error handling
- Fallback processing

Created as part of the n8n N8N102 training program and retained here as
evidence of hands-on implementation.
