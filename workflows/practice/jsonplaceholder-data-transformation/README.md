# JSONPlaceholder Data Transformation

A small n8n practice workflow using the public JSONPlaceholder API.

The workflow retrieves a limited set of users, selects several nested fields, aggregates the records, and then splits data back out for additional processing.

## Concepts Demonstrated

- Public REST API calls
- Query parameters
- Nested JSON field access
- Field mapping
- Aggregation
- Split Out processing
- n8n expressions

## File

`jsonplaceholder-data-transformation.json`

## Classification Note

The exported workflow does not contain reliable course metadata, so it is stored under `workflows/practice/` rather than being assigned to a numbered n8n course.
