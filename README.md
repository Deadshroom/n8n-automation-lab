# n8n Automation Lab

A collection of hands-on n8n workflows created while learning, experimenting with, and applying workflow automation concepts.

This repository serves as a working lab for exploring n8n capabilities including APIs, webhooks, data transformation, AI agents, tool integrations, and automation design patterns.

## What This Repository Contains

Workflows in this repository may include:

- REST API integrations
- Webhook-based automations
- Data transformation and routing
- AI agents and tool usage
- LLM integrations
- External service integrations
- Error handling and workflow logic
- Experiments created during n8n training

## Purpose

The goal of this repository is to document practical experience with n8n while building a growing library of automation examples.

Some workflows originate from structured training exercises and may be modified or expanded as part of continued experimentation.
